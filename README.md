# Oscilloscope Music Lab

A browser-native audio experiment for exploring oscilloscopes, waveforms, FFT spectra, stereo Lissajous figures, phase, frequency ratios, and spectral resynthesis.

## Main features

- Real-time Web Audio oscilloscope and spectrum analyzer
- Local audio file playback and analysis
- Microphone analysis
- YouTube embed with real browser-tab audio capture
- Stereo Lissajous and audio-reactive vector views
- Dual-oscillator signal generator with frequency and phase controls
- RMS, peak, FFT, and rendering readouts
- Persistent floating analyzer while scrolling
- Tone Copy: full-complex-spectrum STFT analysis and inverse-STFT overlap-add resynthesis
- Tone Copy input from local audio or recorded browser-tab audio
- A/B playback of source audio and the generated Tone Copy WAV
- Tone Copy WAV export and routing back into the live analyzer

All audio processing runs in the browser.
