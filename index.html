02 / VISUALIZERS

ONE SIGNAL · FOUR WAYS TO LOOK AT IT

Each view answers a different question about the same audio.

01

Waveform

Plots sample amplitude against time. You see the raw shape of the signal moving through the current analysis window.

x[n]
02

Spectrum

Runs an FFT and groups the frequency bins across a logarithmic frequency axis. This shows where energy is concentrated from bass through treble.

X[k] = FFT{x[n]}
03

Lissajous

Uses one stereo channel for X and the other for Y. Mono, width, polarity, phase, and channel relationships become geometry.

(L(t), R(t))
04

Vector field

Uses live time-domain samples and FFT magnitudes to drive a radial field. It is another mapping of measured signal data, not a pre-recorded animation.

position = f(X[k], x[n], t)
03 / SIGNAL PATH

FROM SPEAKER PRESSURE TO NUMBERS

What the browser is measuring.

Digital audio is a sequence of sample values taken at a fixed sample rate. The analyzer reads those samples directly from Web Audio nodes and derives the different measurements from them.

1

Sample

At 48 kHz, a channel contains 48,000 amplitude samples for every second of audio.

2

Window

An analyzer looks at a short block of neighboring samples so it can measure what the signal is doing at that moment.

3

Transform

The FFT changes the coordinate system from amplitude-over-time to complex frequency bins.

4

Render or rebuild

The bins can be drawn as a spectrum or transformed back into samples with an inverse FFT.

Magnitude

For a complex bin a + ib, its magnitude is √(a² + b²). That is the value most spectrum analyzers turn into bar height.

Phase

The same bin also has an angle atan2(b, a). Tone Copy keeps the real and imaginary components, so this phase information stays in the spectrum used for reconstruction.

Nyquist

A sampled signal can represent frequencies up to half its sample rate. A 48 kHz file therefore has FFT bins from 0 Hz through 24 kHz.

Overlap

Tone Copy windows neighboring frames so they overlap, then overlap-adds the inverse transforms and normalizes the window weights at every output sample.

04 / MATH LAB

CHANGE THE NUMBERS · CHANGE THE SIGNAL

Two sine waves are the simplest place to see frequency and phase.

The generator in the analyzer creates two real Web Audio oscillators. These equations describe the values being changed by the frequency and phase controls.

x(t) = A sin(220 · 2πt + 0)
y(t) = B sin(330 · 2πt + π/2)

Current frequency ratio: 2:3. Whole-number frequency ratios repeat, which is why the Lissajous path closes into a stable pattern.

PHASE IN TIME

A phase offset can be expressed as a time offset: Δt = φ / (2πf). The generator converts the Phase B slider into that delay for the second oscillator.

FORWARD DFTX[k] = Σₙ x[n]e⁻ⁱ²πkn/N

Changes a frame of N time samples into N complex frequency coefficients.

INVERSE DFTx[n] = (1/N)Σₖ X[k]eⁱ²πkn/N

Adds those complex frequency components back together to recover time samples.

RMSRMS = √((1/N)Σₙx[n]²)

Measures the signal's average energy over the current sample block.
