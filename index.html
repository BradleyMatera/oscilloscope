I wanted to understand the concept by building it.

01 / HOW IT WORKS

FROM SOUND TO SCREEN

The browser reads the audio and draws what it finds.

There is no pre-made animation pretending to match the music. When an audio source is connected, the visualizer reads real sample data from the browser's Web Audio API.

1

Get audio

Use a local music file, your microphone, captured tab audio, or the built-in two-tone generator.

2

Measure it

The Web Audio API gives the page waveform samples and frequency data while the sound is playing.

3

Draw it

Canvas redraws the analyzer every frame. The different views use the same audio data in different ways.

4

Change it

The signal controls change frequency, phase, and trail strength so you can see how the result changes.

02 / THE MATH

WHY THE SHAPES CHANGE

Two tones can turn into a shape.

The Lissajous view uses one signal for the horizontal position and another for the vertical position. Change their frequencies or phase in the analyzer above and this math updates with them.

x(t) = A sin(220 · 2πt + 0)
y(t) = B sin(330 · 2πt + π/2)

Current frequency ratio: 2:3. Simple whole-number ratios repeat into stable patterns. Phase changes where the second wave starts, which changes the shape you see.

Change these values in the analyzer ↑
What to try

Start the generated tones, switch to Lissajous, then try the 1:1, 2:3, 3:4, and 3:5 buttons. After that, move the phase slider slowly and watch the same frequency ratio produce different shapes.
