02 / LAB

MATHEMATICS AS UI

Change the equation. Change the image.

The Lissajous view plots one periodic signal against another rather than plotting amplitude against time.

x(t) = A sin(220 · 2πt + 0)
y(t) = B sin(330 · 2πt + π/2)

For frequencies fₓ:fᵧ = 2:3, the curve closes into a stable figure when the ratio is rational. Phase rotates and reshapes the figure without changing that ratio.
